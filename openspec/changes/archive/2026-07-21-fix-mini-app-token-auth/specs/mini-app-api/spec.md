## MODIFIED Requirements

### Requirement: REST API authentication

All REST API endpoints SHALL authenticate requests using the `X-Telegram-Init-Data` header. The server SHALL accept one of two formats in this header:

1. A custom HMAC-SHA256 token with `ma_` prefix (generated by `generateAuthToken()`) — decoded, signature-verified, and expiry-checked
2. A Telegram WebApp initData string — HMAC-SHA256 signature verified using the bot token

In both cases the server SHALL extract the user ID and ensure a tenant exists before processing the request.

#### Scenario: Authenticated request with custom token
- **WHEN** a request is made to any REST API endpoint with `X-Telegram-Init-Data` header containing a valid `ma_` prefixed token
- **THEN** the server SHALL validate the token (signature + expiry)
- **AND** extract the user ID from the token payload
- **AND** process the request for the authenticated user

#### Scenario: Authenticated request with Telegram initData
- **WHEN** a request is made to any REST API endpoint with a valid Telegram WebApp initData in `X-Telegram-Init-Data`
- **THEN** the server SHALL validate via HMAC-SHA256 using the bot token
- **AND** process the request for the authenticated user

#### Scenario: Unauthenticated request
- **WHEN** a request is made without a valid `X-Telegram-Init-Data` header
- **THEN** the server SHALL return HTTP 401

### Requirement: Session REST API (modified)

The session REST API SHALL enforce user ownership on all mutating and detail-read operations.

#### Scenario: Cancel session with ownership check
- **WHEN** a POST request is made to `/api/sessions/:id/cancel`
- **THEN** the server SHALL verify the session belongs to the authenticated user
- **AND** return 404 if the session does not exist or does not belong to the user

#### Scenario: Get session detail with ownership check
- **WHEN** a GET request is made to `/api/sessions/:id`
- **THEN** the server SHALL verify the session belongs to the authenticated user
- **AND** return 404 if the session does not exist or does not belong to the user
